Guitar

An esoteric programming language

Tape based esolang with 6 strings across 20 frets

Start writing the song (header required at top)

Next string / Last string (navigate strings 1 to 6)

Strum string / Mute string (add or subtract one from current string value)

Next frett / Last frett (navigate frets 1 to 20)

Tune (takes input to set value added by strum string command)

Write music sheet (print ascii characters from each string from 1 to 6, fret 1 to 20)

Play the song (footer required to execute code)

Note: positions do not wrap around

Computational class: finite state machine

This includes: guitar.html which is an interpreter
